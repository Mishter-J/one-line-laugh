A program that writes one funny line — a single sentence of at most 200 characters — to `/output/entry.txt` for make.fun's "The One-Line Laugh" bounty. The line was picked from ten original candidates by pairwise judging against the published judge brief: a real surprise at the end that still makes sense, an everyday truth people recognise, and economy of words.

## Run it

```sh
python3 main.py
```
